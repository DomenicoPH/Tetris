# Tetris con Canvas HTML5 y JavaScript
Implementación moderna del clásico juego Tetris utilizando HTML5 Canvas y JavaScript vanilla. Una experiencia de juego fluida con controles intuitivos, sistema de puntuación y diseño responsivo.

## Características
- Gameplay clásico con las 7 piezas de tetrominós

- Renderizado visual con Canvas HTML5

- Animaciones suaves y controles responsivos

- Sistema de puntuación con progresión de niveles

- Controles de teclado (teclas de flecha + espacio)

- Diseño responsivo para desktop y móvil

- Estados del juego (Inicio, Jugando, Pausa, Game Over)

- Vista previa de la siguiente pieza

## Cómo Jugar

    (← →) : Mover pieza izquierda/derecha

    (↑) : Rotar pieza

    (↓) : Caída rápida

    (Espacio) : Caída instantánea

    (P) : Pausar/Reanudar

## Inicio Rápido

1. Clona el repositorio

2. Abre index.html en tu navegador

3. ¡Presiona Iniciar y disfruta!
